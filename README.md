## 真实的缺点，以及哪些人不用买

iTechGuides 在 2026 年 9 月核对过一次，给出 6.8/10 的编辑评分，在它收录的 31 款绘图软件里排第 24 位。这个分数不算高，扣分点也很具体。

没有免费版是第一条。StarUML 只提供试用，没有功能受限的免费档，试用结束就必须买授权才能继续编辑。对预算为零的学生来说，这道门槛比价格本身更难跨。

按设备收费是第二条。个人买一份还好，团队采购的成本会线性叠加，20 台就是标准版 3180 美元。批量价能压一点，但压不掉多少。

集成能力窄是第三条。它的扩展体系围绕 Mermaid、MCP server 和 JavaScript 扩展展开，需要跟一大堆外部服务对接的团队会觉得别扭。实时协作也不是内置功能，要装 LiveShare 扩展才有。

还有一条容易被忽略，买断的是当前大版本。小版本更新免费，跨大版本要再付一次升级费，只是老用户能拿到折扣价。把它当成“一次付费终身免费升级”会失望。

至于授权能不能换机器，定价页上没写明。你如果有一台台式机加一台笔记本，或者半年后要换电脑，下单前花两分钟问一下商城客服，把迁移规则确认清楚，比事后扯皮省事。
